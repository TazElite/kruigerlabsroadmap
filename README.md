# Kruiger Labs Roadmap

Public roadmap data for Kruiger Labs LLC.

This repository is the source of truth for the roadmap displayed by Kruiger Labs. Every roadmap entry includes a description and the date it was added. Completed entries retain their completion date so shipped work remains visible as historical release information.

## Statuses

- Planned
- Near Future
- In Development
- Testing
- Releasing Soon
- Far Future
- On Hold
- Completed
- Cancelled

## Data

`roadmap.json` contains the public roadmap.

`schema.json` defines the supported roadmap structure.

Completed work is not deleted. It moves to `completed` and receives a `completedDate`.
